# 01 · Struct Skeleton (Python)

Python port of `week1_baseline/ruby/01_struct_skeleton`.

This step carries forward the configuration layer from Step 0 and adds the
core `Message`, `Tool`, and `Context` data structures.

## Run

From the repository root:

```bash
./week1_baseline/bin/01_struct_skeleton_py
```

Or from this directory:

```bash
uv run python examples/example.py
```

## Test

```bash
uv run python -m unittest discover
```
